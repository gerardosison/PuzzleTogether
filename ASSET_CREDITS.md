not generated paintings or remote image hotlinks. Interface styling may display
the images in monochrome; the original downloaded files retain their colors.
The files below are unchanged copies. Several Van Gogh reproductions retain a
small source watermark from Rawpixel; no watermark has been removed.

All paintings were published before 1931, and all named artists died more than
70 years ago. These reproductions are of public-domain two-dimensional artworks.
The source repository for the Rawpixel Van Gogh reproductions explicitly links
to [Rawpixel's public-domain Van Gogh collection](https://www.rawpixel.com/board/537381/vincent-van-gogh-free-original-public-domain-paintings).
Source repository software licenses do not replace the underlying artwork's
public-domain status. No modern copyrighted style-transfer output is included.

The selected museum reference supplied by the user informs the architectural
spacing and exhibition-label treatment; that reference photograph is not bundled
or represented as a gallery asset.

## Museum hero

`public/art/museum.png` is an original AI-generated black-and-white architectural
scene created for this website from a description inspired by the user's museum
reference. It is not a documentary photograph or a reproduction of that reference.
